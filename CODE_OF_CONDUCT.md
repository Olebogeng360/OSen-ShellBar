# Code of Conduct

## Our standard

Contributors must communicate respectfully, discuss technical decisions in good faith, and focus criticism on code and behavior rather than people.

Unacceptable conduct includes harassment, threats, discriminatory language, deliberate disruption, publishing private information, and knowingly encouraging unsafe use of preview builds.

## Scope and enforcement

This policy applies to repository issues, pull requests, discussions, code review, and project-managed community spaces. Repository maintainers may edit, hide, lock, or remove content and may restrict participation when necessary.

Report conduct concerns privately to the repository owner. Do not use public issues for sensitive reports.
